Hypergraph research workbench

Automorphism Group Explorer

Enumerate vertex permutations that preserve a hypergraph, compute the automorphism group order, inspect all automorphisms, and partition vertices into symmetry orbits.

Hypergraph input

Include isolated vertices here. Vertices appearing in edges are added automatically.

Separate edges with commas between braces, semicolons, or new lines. Example: {1,2}, {2,3,4}

Automorphisms are vertex permutations that preserve the edge family. Edges are treated as an unordered set; duplicate input edges are ignored for the group computation.

Results

Enter a hypergraph and click Compute.

Exhaustive enumeration is factorial-time. The tool is intended for small hypergraphs (typically up to 8 vertices); degree pruning improves speed but does not remove worst-case factorial growth.
