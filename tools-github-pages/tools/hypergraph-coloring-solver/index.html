Hypergraph Coloring Solver

Find weak or strong vertex colorings using exact backtracking with a saturation-based vertex choice heuristic. Search for a coloring using the fewest colors up to your selected limit.

Hypergraph input

Include isolated vertices here. Vertices appearing in edges are added automatically.

Separate edges with commas between braces, semicolons, or new lines. Example: {1,2}, {2,3,4}

Results

Enter a hypergraph and click Compute.

Exact coloring is computationally hard. This tool uses a bounded backtracking search and is intended for small/medium examples; a search-limit message means the answer is inconclusive, not proof that no coloring exists.
