Hypergraph Edge Orbits

Enter the edges of a hypergraph and a permutation of its vertices. Generate a table showing each edge's successive images under the permutation.

01 · Define your hypergraph

Use braces or plain comma-separated vertices. Separate edges with commas or new lines.

Example: {1,2}, {2,3}, {1,3}

Enter a cycle, e.g. (1 2 3), or a mapping, e.g. 1→2, 2→3, 3→1.

Your table will appear here

Each edge gets its own column, labeled \(E_1, E_2, \ldots\). Rows show the edge images after applying the permutation repeatedly.

03 · Edge-orbit graph

Waiting for input

Each vertex represents one input edge. Two vertices are connected exactly when their edges belong to the same orbit under the permutation. Vertices in the same orbit share a color. Drag vertices to rearrange the graph.

Convention: row \(k\) displays \(\sigma^k(E_i)\), where \(\sigma^0(E_i)=E_i\). The table includes enough rows to show each edge orbit once, up to the maximum edge-orbit length. In the graph, every pair of input edges in the same permutation orbit is connected. Math labels are rendered with MathJax when available.
