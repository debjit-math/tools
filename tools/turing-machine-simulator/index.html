How to write transitions

Each rule maps a state and scanned symbol to a new state, a symbol to write, and a direction.

qStart, 0 -> qMove, X, R

  • One rule per line; commas separate the five fields.
  • Duplicate (state, symbol) pairs are not allowed.
  • Moves are L or R. The tape extends with blanks automatically.
  • States and symbols may be multi-character tokens; separate input symbols with commas in the alphabets.

What does halt mean?

The machine accepts when it enters qaccept, rejects when it enters qreject, and gets stuck if no rule matches the current state and symbol.

Use Step to inspect a single transition. Use Run to execute until halt or the safety limit (10,000 steps). The tape shown is a window into a tape that extends indefinitely in both directions.
