Hypergraph research workbench

Transversal & Hitting-Set Solver

Find vertex sets that intersect every hyperedge. Compute a minimum transversal, enumerate all minimal transversals, and inspect which edges each candidate hits.

Hypergraph input

List isolated vertices too, if any.

Example: {1,2}, {2,3,4}. Separate edges by commas after braces, semicolons, or new lines.

Results

Enter a hypergraph and click Compute.

A transversal (hitting set) meets every edge. A minimal transversal has no proper subset that is also a transversal; a minimum transversal has smallest cardinality. The search is exponential and capped for browser responsiveness.
