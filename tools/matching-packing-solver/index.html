Matching & Packing Solver

Find maximum matchings and enumerate maximal matchings in a hypergraph. Results include edge labels, matching sizes, search diagnostics, and downloadable JSON.

Hypergraph input

Include isolated vertices here. Vertices appearing in edges are added automatically.

Separate edges with commas between braces, semicolons, or new lines. Example: {1,2}, {2,3,4}

A matching is a set of pairwise vertex-disjoint edges. A maximal matching cannot be extended; a maximum matching has largest possible size.

Enter a hypergraph and click Compute.

Exact matching is exponential in the worst case. This page uses exhaustive branch-and-bound and a search-node budget; if the limit is reached, the result may be incomplete. Empty edges are not recommended for matching problems.
